## 一、原来为什么在真机上连不上

小程序里的 `wx.request` 有两个硬性前提：

1. 域名必须在 **mp.weixin.qq.com → 开发管理 → 开发设置 → 服务器域名** 里登记；
2. 域名必须**已完成 ICP 备案**，且 https 证书有效。

「不校验合法域名」这个勾只在开发者工具里有效，**真机预览和体验版一律强制校验，无法绕过**。

而 Cloudflare 临时隧道给的域名（`xxx.trycloudflare.com`）不属于我们、备不了案，也没法在
它根目录放微信要求的校验文件 —— 所以它**永远**进不了白名单。体验版在手机上必然全失败，
报的正是我们代码里的兜底文案「连不上服务器」。

之前那次「全链路跑通」，跑的是 Web 版和开发者工具，真机体验版这条路一直没通。

## 二、换成云开发为什么就好了

`wx.cloud.callFunction` 走的是微信自己的内部通道，**不经过 request 合法域名校验，也不需要备案**。

顺带还解决了三件事：

- 身份不用再自己发 token —— 云函数里 `cloud.getWXContext().OPENID` 就是可信的用户标识；
- 照片直接传云存储，`<image src="cloud://...">` 原生支持，不用再把 base64 塞进 JSON；
- 数据库、存储、函数都在一个后台里，不用再维护一台电脑和一条随时会断的隧道。

费用：2025-02-19 起，每个**没有云环境**的小程序账号可以免费创建 1 个云环境，
**在小程序未发布上线期间不需要续费**（活动截止 2026-12-31）。我们走体验版、不正式发布，
正好落在免费范围内。

## 三、你需要做的（只有两步）

### 第 1 步：开通云开发

1. 浏览器打开 <https://mp.weixin.qq.com>，用小程序管理员微信扫码登录；
2. 左侧菜单找 **开发 → 云开发**（有的版本叫「开发管理 → 云开发」）；
3. 点 **开通**，主体类型选**个人**即可；
4. 建一个环境：
   - 环境名称：随便，比如 `spacetime`
   - 计费方式：选 **免费** / 基础版
   - 地域：选**上海**（离得近）
5. 建好后，环境列表里会出现一个 **环境 ID**，形如 `spacetime-8g0abcde12345678`。
   把这个 ID 复制下来。

> 环境 ID 不是环境名称。名称是 `spacetime` 这种你自己起的，ID 后面带一串随机字符。

### 第 2 步：把环境 ID 告诉我

两种方式，任选：

- 直接把环境 ID 发我，我填进 `miniprogram/config.js` 并部署；
- 或者你自己填：打开 `miniprogram/config.js`，把
  ```js
  const CLOUD_ENV = '';
  ```
  改成
  ```js
  const CLOUD_ENV = 'spacetime-8g0abcde12345678';
  ```

填完就不用管了，后面的部署、上传、出二维码我来。

## 四、开通后我会做什么

```bash
./scripts/deploy.sh <环境ID>     # 部署云函数 api（依赖在云端装）
./scripts/upload.sh 1.0.1 "换成云开发后端"
```

云函数第一次被调用时会自动建好 4 个集合（`users` / `photos` / `pairs` / `meta`），
并播入 3 位演示用户，所以你进去就能直接匹配到人，不用先准备数据。

一旦出现「对方照片是一片空白/加载不出来」，去
**云开发控制台 → 存储 → 权限设置**，确认是
**「所有用户可读，仅创建者可写」**。如果被设成了「仅创建者可读写」，
你只能看到自己的照片，看不见对方的。

## 五、如果不开通云开发，还有别的路吗

| 方案 | 真机体验版可用 | 成本 | 代价 |
|---|---|---|---|
| **云开发**（现在这条） | ✅ | 免费（未上线期间） | 后端要改成云函数，已完成 |
| 备案域名 + 云服务器 | ✅ | 域名 ~50/年 + 服务器 ~40/月 | ICP 备案 1–4 周 |
| 只给朋友用手机浏览器开 Web 版 | ❌ 不是小程序 | 0 | 保留旧隧道，域名随时会断 |
| 只在开发者工具里看 | ❌ | 0 | 发不给别人 |

## 六、常见报错对照

| 手机上的提示 | 真实原因 | 怎么办 |
|---|---|---|
| 连不上服务器 | 云函数没部署 / 环境 ID 不对 | 跑 `./scripts/deploy.sh` |
| 云函数 api 还没部署 | `cloudfunctions/api` 没上传 | 同上 |
| 云开发环境没选对 | `CLOUD_ENV` 写错或环境被删 | 核对环境 ID |
| 拿不到微信身份 | 在开发者工具「云函数测试」里直接调了 | 只能从小程序里调 |
| 这套基础库不支持云开发 | 调试基础库低于 2.2.3 | 详情 → 本地设置 → 调试基础库调高 |
