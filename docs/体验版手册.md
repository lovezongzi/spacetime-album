## 一、后端在哪：微信云开发，不是自己的服务器

小程序端不连任何自建服务，全部走 `wx.cloud.callFunction`：

```
小程序  ──callFunction──▶  云函数 api  ──▶  云数据库 users / photos / pairs / meta
                                          └─▶  云存储（720px 缩略图）
```

这意味着：

- **不用域名、不用备案、不用管 TLS** —— 微信内部通道，不经过 `request` 域名白名单
- **不用你这台 Mac 常开** —— 关机上床睡觉，朋友的体验版照样能玩
- **不用配置「开发调试」** —— 朋友扫码就是正常打开，没有 vConsole 那一步

为什么必须这么做，见文末「附：为什么放弃了隧道」。

云开发的免费额度：2025-02-19 起，没有云环境的账号可建 1 个免费环境，小程序未发布上线期间不需要续费（活动到 2026-12-31）。

## 二、改了代码之后怎么发新版本

```bash
cd /Users/zongzi/WorkBuddy/时空相册

# 只改了云函数（后端逻辑）
./scripts/deploy.sh sit-d3gjwf9ba4e469265

# 只改了页面（前端）
./scripts/upload.sh 1.0.3 "改了什么"

# 两边都改了：先 deploy 再 upload
```

`upload.sh` 就是包一层开发者工具 CLI：

```bash
/Applications/wechatwebdevtools.app/Contents/MacOS/cli upload \
  --project /Users/zongzi/WorkBuddy/时空相册/miniprogram \
  -v 1.0.3 -d "改了什么"
```

两个已知坑：

1. **CLI 的退出码永远是 0**，即使内部报 `✖`。所以脚本改成抓输出里的 `✖` 判断成败，别只看退出码。
2. **输出路径只能写在项目目录里**，写 `/tmp` 会报「二维码输出路径无效」。所以预览码落在
   `miniprogram/preview-qr.png` —— 但这个文件会被打进小程序包（98 KB → 146 KB，1.0.1 因此白传过一次），
   已在 `project.config.json` 的 `packOptions.ignore` 里排除。上传前扫一眼体积。

## 三、转成体验版（只能你在网页端点）

1. 打开 https://mp.weixin.qq.com 扫码登录
2. **管理 → 版本管理** → 「开发版本」里找到 **1.0.2** → 点 **选为体验版**
3. **管理 → 成员管理 → 体验成员**，把朋友的微信号加进去（上限 100 人，可以随时增减）
4. 回版本管理页，下载**体验版二维码**发给朋友

体验版本身不会过期（开发版本会）。以后传了 1.0.3，要重新点一次「选为体验版」。

## 四、朋友扫码之后

直接就能用，**不需要**开调试模式。但有一件事需要你提前确认：

**云开发控制台 → 存储 → 权限设置**，选「所有用户可读，仅创建者可写」。
否则 A 上传的照片 B 读不到 —— 交换房间左边有图、右边空白。

其余照常：起个名字 → 载入示例相册 → 遇见 → 随机一天 → 交换 → 等几秒对方接受 → 各按一次「展示」→ 互相可见。

## 五、可能会卡住的点

| 现象 | 原因 | 解法 |
| --- | --- | --- |
| 「云环境还没开通」 | 环境 ID 没填对，或环境被删了 | 核对 `miniprogram/config.js` 的 `CLOUD_ENV` |
| 「云函数 api 还没部署」 | 只传了小程序、没传云函数 | `./scripts/deploy.sh <环境ID>` |
| 云函数偶发超时 | 控制台里超时是 **3 秒**，`config.json` 写的 20 秒 CLI 没采纳 | 云开发控制台 → 云函数 `api` → 配置 → 超时改 20 秒 |
| 第一次调用特别慢 | 冷启动 + 建集合 + 播种 20 张照片 | 正常，之后就快了 |
| 交换房间里对方照片空白 | 云存储权限不对 | 控制台 → 存储 → 权限改成「所有用户可读」 |
| 上传报 `unbound appid` | 当前登录的微信不是这个小程序的管理员/开发者 | 公众平台 → 成员管理，把自己加为开发者 |
| 包体突然变大几十 KB | 预览二维码被打进包了 | 确认 `packOptions.ignore` 里有 `preview-qr.png` |

## 六、想升级成正式版时

体验版验证得差不多了，再回来看 `docs/上线路线.md`：

- **个人主体上不了「社交 → 陌生人交友」类目**，需要企业主体 + ICP 许可证。要么改定位
  （从「随机匹配陌生人」改成「定向邀请朋友」），要么换主体。
- 后端已经不需要备案域名了（云开发），卡点只在**类目与资质**，不在技术。
- 备案还是要做，但那是小程序备案，个人可办、免费、约 1–2 周，和域名备案不是一回事。

## 附：为什么放弃了隧道

最初的做法是：本机 Node 服务 → Cloudflare 临时隧道 → 小程序 `wx.request`。Web 版和开发者工具里全链路都通了，
但真机体验版一直「连不上服务器」。

根因是平台硬规则：**`wx.request` 的域名必须在后台「服务器域名」登记，且必须已完成 ICP 备案。**
「不校验合法域名」这个开关只在开发者工具本地生效，真机预览和体验版一律强制校验，无法绕过。
`trycloudflare.com` 不是自己的域名、备不了案、也没法在它根目录放校验文件，所以永远进不了白名单。

更坑的是：隧道会**被 Cloudflare 主动回收**（实测活不过几天）。进程还在跑、日志还在刷重试，
但每次请求都失败 —— 所以判断隧道是否可用不能看 `pgrep`，得 `curl /api/health`。

这条路是死胡同，已整体换成云开发。旧代码（`server/` + `public/`）留着给网页版用，`scripts/tunnel.sh` 仅作历史遗留。
