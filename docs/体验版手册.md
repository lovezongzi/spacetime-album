# 体验版上手指南（路 C）

目标：让朋友用微信扫码就能玩到，不走审核、不选类目、不花一分钱。
代价：搜不到、不能公开传播、体验成员上限 100 人。

---

## 一、服务端：已经跑起来了

本地 Node 服务通过 Cloudflare 隧道对外暴露：

```
https://gerald-joined-builders-recorders.trycloudflare.com
```

已验证公网全链路：登录 → 载入相册 → 随机一天 → 发起交换 → 对方接受 → 双向展示。

**注意两件事：**

1. 这是**临时隧道**，进程一停地址就失效。重新开：`./scripts/tunnel.sh`，
   拿到新地址后改 `miniprogram/config.js` 的 `BASE_URL`，重新上传一次体验版。
2. 服务跑在你这台 Mac 上。**关机 / 合盖休眠，朋友的体验版就打不开。**
   要长期给人玩，得放到一台常开的机器上（云服务器、家里的 NAS、旧笔记本都行）。

---

## 二、注册小程序，拿 AppID（只有你能做）

这一步必须你本人操作：要身份证 + 微信扫码人脸识别。

1. 打开 https://mp.weixin.qq.com/wxopen/waregister?action=step1
2. 填一个**没注册过公众平台的邮箱**（QQ 邮箱可以用，但企业邮箱常被安全网关吃掉验证邮件）
3. 去邮箱点激活链接
4. 主体类型选 **个人**（免费，不用 300 元认证费）
5. 身份证信息 + 管理员微信扫码人脸识别
6. 填小程序名称、头像、简介
   - 名称不能和已有小程序重名，「时空相册」很可能被占，准备两三个备选
   - 头像随便传张图，体验版不审核这个
7. 注册完进入后台 → **开发管理 → 开发设置 → 开发者 ID**，复制 **AppID**（wx 开头 18 位）

拿到 AppID 后告诉我，或者自己填：

```bash
# miniprogram/project.config.json 里改这一行
"appid": "wx1234567890abcdef"
```

## 三、上传并转成体验版

### 方式一：命令行（推荐，一条命令）

```bash
cd /Users/zongzi/WorkBuddy/时空相册
./scripts/upload.sh 1.0.0 "第一个体验版"
```

前提：开发者工具已登录、服务端口已开（我们已配好）。

### 方式二：界面

开发者工具 → 右上角「上传」→ 填版本号和备注 → 上传。

### 上传之后

1. 打开 https://mp.weixin.qq.com → **管理 → 版本管理**
2. 在「开发版本」里找到刚传的版本 → 点 **选为体验版**
3. 到 **管理 → 成员管理 → 体验成员**，把朋友的微信号加进去（上限 100 人）
4. 在版本管理页面下载**体验版二维码**，发给朋友

## 四、朋友扫码后必须做的一步（关键）

体验版在真机上**默认仍然校验服务器域名白名单**，而我们用的是临时的 trycloudflare 域名，
不在白名单里，会报 `request:fail url not in domain list`。

解法：让朋友在小程序里打开调试模式——

1. 微信里打开这个小程序
2. 点右上角 **···**
3. 选 **开发调试**
4. 小程序会重启，右上角出现 vConsole 图标，这时就能正常请求了

这一步每次重装/清除缓存后可能要重做。烦，但体验版只能这样。

## 五、完整流程（你这边）

```
① 注册小程序，拿 AppID
        ↓
② 填进 miniprogram/project.config.json
        ↓
③ ./scripts/tunnel.sh   ← 服务端出公网地址（服务已在跑可跳过）
        ↓
④ 把地址填进 miniprogram/config.js 的 BASE_URL
        ↓
⑤ ./scripts/upload.sh 1.0.0 "第一个体验版"
        ↓
⑥ 公众平台 → 版本管理 → 选为体验版
        ↓
⑦ 成员管理 → 加体验成员 → 发体验版二维码
        ↓
⑧ 朋友扫码 → 点右上角 ··· → 开发调试 → 开玩
```

## 六、可能会卡住的点

| 现象 | 原因 | 解法 |
| --- | --- | --- |
| `不存在此 AppID (code 10)` | 还是测试号，没填真实 AppID | 改 `project.config.json` 的 appid |
| `request:fail url not in domain list` | 没开开发调试 | 右上角 ··· → 开发调试 |
| 停在登录页转圈 | 隧道挂了 / Mac 休眠了 | 重开隧道，改 `config.js` 重传 |
| 上传报 `unbound appid` | 登录的微信不是该小程序的管理员/开发者 | 公众平台 → 成员管理，把当前微信加为开发者 |
| 提示需要先备案 | 部分情况体验版也会拦 | 公众平台 → 设置 → 备案信息，走小程序备案（个人可办，免费，约 1-2 周） |
