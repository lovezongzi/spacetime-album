# 小程序头像

<img src="icon-192.png" width="96" align="left" hspace="16" vspace="4" />

两轮落日：左边那轮还悬在天上，右边那轮正沉进地平线。它们在同一条地平线上错开、交叠，交叠的那一块被两份光同时照亮 —— 亮到发白。

这是「时空相册」的整个想法：**我们各自看着自己的那场日落，直到某一天，两场日落落在了同一块地方。**

## 直接上传用哪个

微信公众平台 → 设置 → 基本设置 → 小程序头像。

| 文件 | 尺寸 | 用在哪 |
| --- | --- | --- |
| `icon-144.png` | 144×144 | **上传这个**。16KB，远低于 2MB 上限，微信会自己裁圆 |
| `icon-512.png` | 512×512 | 需要更高清的场景：分享卡片、宣传图、应用市场 |
| `icon-1024.png` | 1024×1024 | 母版，任何尺寸都从它派生 |
| `icon.svg` | 矢量 | 改颜色、改构图时的源文件，无损缩放 |

微信在列表、聊天、搜索结果里都会把头像裁成**圆形**，所以设计时按圆形安全区来做：全部关键内容都落在内切圆里，四角只放渐变，被裁掉也不影响。

## 缩到多大还认得出来

`preview-round.png` 是 144 / 96 / 64 / 40px 的圆形实机预览。40px 是微信会话列表里的真实尺寸，那个尺寸下细节都会糊掉，剩下能认的只有三样东西：

1. 暖色（在一片冷色的其他头像里跳出来）
2. 两个圆的轮廓
3. 中间那块最亮的白

所以构图刻意只保留这三层，没有加文字、没有加相框、没有加多余的山。**任何新增元素在 40px 下都会变成脏点，别加。**

## 配色

取自小程序本体的日落色系，和 `app.wxss` 里那套一致：

| 用途 | 色值 |
| --- | --- |
| 天顶 | `#191030` |
| 高空 | `#2A1C44` |
| 中层 | `#4E2C55` |
| 地平线暖光 | `#FFA55F` |
| 太阳 A（未落） | `#FF9364` → `#EA5535` |
| 太阳 B（沉没） | `#C9687F` → `#6B2544` |
| 交叠处 | `#FFF8E6` |
| 地面 | `#3A2138` → `#170E24` |

太阳 B 比 A 暗一档是刻意的 —— 越接近地平线的太阳越红越暗，这是物理；同时它让"亮 / 白 / 暗"三层明度分开，缩到 40px 才不会糊成一团。

## 改完怎么重新出图

```bash
./render.sh
```

改 `icon.svg` 后跑一次就行。脚本会用 Chrome 无头模式把 SVG 渲染成 1024，用 `sips` 派生出 512 / 192 / 144 / 96，再生成圆形预览图。

注意两点，都是踩过的坑：

- **不要直接打开 `.svg` 截图**。Chrome 会给 SVG 加一圈视口留白，导出的 PNG 底部会多出一条白边。脚本里用 `width:100vw;height:100vh` 把 SVG 拉满视口来规避。
- 渲染必须走 Chrome，`sips` 不支持 SVG 输入，macOS 的 `qlmanage` 出来的尺寸和色彩都不稳。
